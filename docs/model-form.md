# 不读源码，直接在网页修改模型

模型可以通过表单修改，不需要寻找 `build_model`、编辑 Python 文件或手写 F/H。你只需要确定状态是什么、它们怎样变化、传感器会观测到什么，以及噪声有多大。

## 打开入口

1. 启动应用，在右侧选中或复制一个滤波器实例。
2. 展开 **“预测模型与方程”**。
3. 将“模型来源”改为 **“表单配置模型（无需 Python）”**。
4. 选择“模型模板”，点击“使用此模板”。加载模板会替换该模型的状态、初值、初始方差、方程和 Q/R，不会改变左侧真实运动场景。

表单修改会自动保存到当前草稿；点击“保存配置”可下载 JSON，再次导入后仍显示表单。未完成或不合法的公式会在验证 / 运行时报告位置，不会偷偷运行上一份有效公式。历史结果保持不变，修改后需要开始新运行。

## 三种模板怎样选

| 模板 | 状态 | 使用条件 |
|---|---|---|
| 11 维：平移、自旋与板几何 | `cx,cy,zA,vx,vy,vz,theta,omega,rA,rB,dh` | 需要估计平移、自旋、半径和高度；可配合现有默认场景 |
| 4 维：平面匀速，已知姿态与几何 | `cx,cy,vx,vy` | 板姿态固定为零，高度和几何已知；适合作为入门例子 |
| 6 维：平面匀速与测量偏置 | 上述四维加 `bx,by` | 同样要求固定姿态；用于学习如何增加状态与改变观测关系 |

四维 / 六维模板不会自动关闭场景自旋。使用它们之前，在左侧把“平移方式”设为“匀速”，初始参考角设为 0，并将自旋组合中所有正弦项的 A、C 设为 0（或删除正弦项）。否则模型假设与真实运动不一致。

## 状态表：每一项应该填什么

展开“状态向量 x”，每张卡片对应一个状态：

| 字段 | 填写方法 | 例子 |
|---|---|---|
| 名称 | 公式中使用的名字，英文字母开头、其后为英文字母 / 数字 / 下划线，唯一且最多 64 字符；不能与公式变量、函数或 Python 关键字重名 | `cx`、`vx`、`bx` |
| 单位 | 对应物理单位 | `m`、`m/s`、`rad` |
| 初值 x₀ | 你在实验开始前的估计，不自动读取真值 | 中心 x 填 `0`，x 速度填 `0.5` |
| 初始方差 P₀ | 初始估计的不确定性，填标准差的平方 | 误差标准差 0.2 m，填 `0.04` |
| 角度状态 | 只有具有 2π 周期的角度才勾选 | `theta` 勾选，`omega` 不勾选 |
| 真值对应 | 该状态表示的物理量，用于显示轨迹和计算误差 | `cx` 对应“中心 x”，偏置选“无对应” |
| 下一时刻公式 | 用当前状态计算经过 dt 秒后的这个状态 | `cx + vx*dt` |

每一行的公式都读取同一个旧状态，不会读到上一行刚更新的结果。可以上移、下移、添加、删除状态；系统同步调整向量顺序、P₀ 和 Q。改名或删除状态后，仍要修改其他公式中引用的名称。

真值对应不是观测通道，也不会给滤波器提供真实答案。选择对应关系后要使用该物理量的单位，例如中心必须是 m；任意新增的内部状态可选“无对应”，NEES 只统计有真值的部分。

## 示例一：只修改匀速模型的初值和噪声

选择四维模板后，展开四张状态卡片，填写：

| 名称 | 单位 | 初值 | 初始方差 | 下一时刻公式 |
|---|---|---:|---:|---|
| cx | m | 0 | 0.04 | `cx + vx*dt` |
| cy | m | 0 | 0.04 | `cy + vy*dt` |
| vx | m/s | 0.5 | 1 | `vx` |
| vy | m/s | 0 | 1 | `vy` |

默认观测公式保留。点击“验证模型”，通过后开始运行。若想比较“更相信运动模型”与“更相信观测”，可复制实例并单独调整 Q 或 R。

展开 Q，矩阵行列用状态名标注。四维模板默认是连续白加速度强度 0.2，对应：

| Q 行 / 列 | cx | cy | vx | vy |
|---|---|---|---|---|
| cx | `0.2*dt**3/3` | `0` | `0.2*dt**2/2` | `0` |
| cy | `0` | `0.2*dt**3/3` | `0` | `0.2*dt**2/2` |
| vx | `0.2*dt**2/2` | `0` | `0.2*dt` | `0` |
| vy | `0` | `0.2*dt**2/2` | `0` | `0.2*dt` |

例如要将 X 轴过程噪声强度从 0.2 改为 1.0，应修改 `cx,cx`、`cx,vx`、`vx,cx`、`vx,vx` 四个格子中的系数。矩阵两个相关项要一起改；只改一边会不对称。dt 是实际预测间隔，不要直接写死为 0.02。

R 的行列固定为 x、y、z、yaw。独立位置噪声标准差 0.03 m、yaw 标准差 0.02 rad，应把 R 对角线改为 `0.03**2, 0.03**2, 0.03**2, 0.02**2`，其余填 0。这改变滤波器假设；左侧“真实观测协方差”独立设置，不会跟着改变。

## 示例二：不用写 Python，增加一个测量偏置状态

从四维模板开始：

1. 点击“添加状态”，将新状态名称改为 `bx`，单位填 `m`。
2. 初值填 `0`，初始方差填 `0.0001`，不勾角度，“真值对应”保留“无对应”。
3. “下一时刻公式”填 `bx`，表示偏置的平均值不随预测改变。
4. 展开 Q，在新增的 `bx,bx` 格填 `0.000001*dt`，与其他状态的相关项填 0。
5. 将“预测观测 x 公式”从 `cx + plate_radius*cos(plate_offset)` 改为 `cx + plate_radius*cos(plate_offset) + bx`。
6. 其他观测公式和 R 不变，点击“验证模型”，通过后开始新运行。

现在是五维模型，系统会自动构造五维初值、5×5 的 P₀/Q，并为 EKF 计算 5×5 的 F、单板 4×5 的 H。无需修改任何函数。六维模板则同时加入 bx/by，可直接对照。

这里偏置影响预测的测量值，不应加到物理中心显示上。当前模拟器没有固定传感器偏置；仅有这些观测时，cx 与 bx 的常量部分也无法唯一分离。此例用于说明模型修改流程，若要识别真实偏置，需要独立约束或标定数据。

## 示例三：改变状态转移，F 自动随公式改变

四维模板中，如果你想让 x 速度按已知时间常数缓慢衰减，可将这两行一起改成：

| 状态 | 下一时刻公式 |
|---|---|
| cx | `cx + vx*(1-exp(-0.5*dt))/0.5` |
| vx | `vx*exp(-0.5*dt)` |

这表示速度每秒按衰减率 0.5 变化，位置公式对应同一条连续衰减曲线。F 将自动对新公式求导，不用手写矩阵。

修改动力学也要重新考虑 Q。原来的白加速度 Q 不再是该衰减动力学的精确离散化；如只想先测试确定性衰减，可将 Q 全部填 0，保留正定 P₀ 和 R。此时仍可依靠观测校正，但不会额外注入过程不确定性。场景不一定符合衰减假设，结果好坏需通过实验判断。

## 观测公式、F/H 和公式语法

实际观测仍为每板 `[x,y,z,yaw]`。表单中的四行 h 是“模型预测传感器会测到什么”；系统按实际板 ID 拼接多板观测，并为每块板重复使用同一个 4×4 R 块，假设不同板的白噪声独立。

F 是状态转移公式对状态的导数，H 是观测公式对状态的导数。EKF 用中心有限差分自动计算；UKF 直接传播状态与观测公式，不使用 F/H。表单模式不提供手填 F/H，也暂不支持跨板相关的 16×16 R；需要这些功能时才使用高级 Python 方式。

| 可用内容 | 写法 / 含义 |
|---|---|
| 四则运算、乘方、取模、括号 | `+ - * / ** %`，例如 `0.01**2`；乘法必须写 `*`，`^` 不能代替乘方 |
| 数学函数 | `sin cos tan exp sqrt abs min max`，例如 `max(vx,0)` |
| 常量 | `pi`；角度公式均用弧度 |
| 预测时间 | 状态公式可用 `dt`、`t0`；Q 只可用 `dt` |
| 场景几何 | `radius_a,radius_b,height_a,height_diff,reference_id`，所有表格可用 |
| 当前板信息 | 仅 h 可用 `plate_id,plate_odd,plate_offset,plate_radius,plate_height` |

`plate_offset=(plate_id-reference_id)*pi/2`，`plate_odd` 在奇数板为 1、偶数板为 0；`plate_radius` 和 `plate_height` 取左侧场景的已知几何。11 维模板估计半径 / 高度时，观测公式使用状态 rA/rB/zA/dh，而不是这些已知常量。

R 只能使用数字、数学函数和几何量；不能依赖状态或 dt。Q 也不能依赖当前状态。暂不支持条件语句、向量下标或外部函数。公式语法错误、未知名称、除零、维数错误和非法协方差会报告到具体行 / 格。

状态数量为 1…32；每个公式最多 512 字符，内部语法节点最多 128 个。`min` / `max` 至少需要两个标量参数；其余函数各接收一个参数。公式必须返回有限实数，Q 必须对称半正定，R 必须对称正定。“验证模型”只检查一组状态、板上下文和代表性时间步，不能证明所有后续状态 / 时间下都合法；例如含 `sqrt(vx)` 的公式可能在 vx 变负后失败。

## IMM 和完整初始协方差

IMM 默认各模式共用父模型。先在父实例选表单模型，再调整各模式的 Q/R 倍率即可。如果需要不同方程，关闭该模式的“使用父模型方程”，选择“独立表单模型”。外层和所有模式的状态名称、单位、顺序、角度标记须一致；各模式共享 x₀/P₀。

状态表可编辑 P₀ 对角方差。需要初始相关项时，可在“初始状态 x₀ / P₀”展开完整 P₀ 矩阵修改；表单会保留已有相关项，并在重排状态时按名称同步。加载全新模板会按新状态名称保留可对应的相关项，请检查是否仍符合新模型假设。

## `build_model` 究竟在哪个文件

**表单方式不需要修改 `build_model`。** 系统自动保存一小段入口源码，实际公式由表单参数生成。下面仅用于定位已有高级入口：

| 使用方式 | 对应文件 / 保存位置 |
|---|---|
| 网页表单 | 自动入口文本定义在 [formulaModel.ts](../web/src/filters/formulaModel.ts) 的 `FORMULA_MODEL_SOURCE`；表单执行器是 [formula.py](../backend/src/filtervisual/models/formula.py) |
| 网页高级 Python 默认模板 | [custom.py](../backend/src/filtervisual/models/custom.py) 的 `TEMPLATE` 字符串内，末尾定义 `build_model`；编辑器保存的是该源码副本 |
| 11 维 Python 示例 | [examples/models/custom_cv.py](../examples/models/custom_cv.py) 末尾的 `build_model` |
| 四维 Python 示例 | [examples/models/reduced_xy.py](../examples/models/reduced_xy.py) 末尾的 `build_model` |
| 六维偏置 Python 示例 | [examples/models/custom_xy_bias.py](../examples/models/custom_xy_bias.py) 末尾的 `build_model` |
| 已导出 / 已保存的模型 | 配置中相应 `models[].source` 的源码文本；不会自动读取磁盘示例文件 |

若确实需要超出表单能力的模型，再参考 [高级 Python 模型说明](model-authoring.md)。
