# FilterVisual 设计说明

日期：2026-10-15。状态：首轮实现之前的历史设计与实施依据。下文关于仓库现状和待实现事项保留原始讨论语境；当前功能和验证以 [1.0 发布记录](../../releases/1.0.md) 及 [使用说明](../../getting-started.md) 为准。

## 1. 用途和完成标准

构建一个本地运动仿真与滤波调参实验台。使用者配置 RoboMaster 四装甲板目标的几何、中心平移和自旋，编辑 EKF、UKF、IMM 的模型与参数，在同一观测来源下比较状态拟合、未来装甲板位置预测和不确定性。结果需要支持复现，能解释“哪里更好、哪里不一致、下一次试什么参数”。

仓库目前仅有 README 和 LICENSE，没有既有产品代码或技术栈。`.superpowers/brainstorm/` 中的页面是讨论草图，曲线是示意数据，不能作为已完成的滤波算法使用。

### 用户已明确的要求

1. XY 平移可设置速度范围；自旋可由多个 `A sin(Ωt+a)+C` 项组成。
2. 四块装甲板模型，可设置两组半轴长度、板高差，并指定一块板作为自旋参考。
3. 自定义 EKF、UKF、IMM，允许多实例比较，并直接修改仿真值和滤波器参数。
4. 保留运动动画、状态真值与估计拟合图、误差图；支持叠加与并排比较。
5. 每个滤波器可设置一个“正常预测 → 观测更新”周期的频率。
6. 每次正常周期完成实际观测更新后，可立即附带 N 次纯预测；时间是预测未来多少秒后的状态。
7. 开启附带纯预测后，显示预测结果与对应未来真值的差距曲线。
8. 增加 NIS、NEES、比较总结和参数调整建议。

### 为形成可执行方案而采用的建议默认值

这些是本方案的设计选择，不代表用户已经逐项确认；审阅时可以替换。

| 事项 | 建议默认值 |
| --- | --- |
| 平台 | 单用户、本地 Web app；React/TypeScript 界面，Python 数值后端 |
| 四板结构 | A0/A2 等距等高，A1/A3 等距等高；相邻板相差 90° |

| 观测 | 已知板 ID 的合成 `[x,y,z,yaw]`；默认单板朝向视点选择，另提供指定板和全部四板模式 |

## 2. 技术和全局约束

- Python >=3.10；兼容当前环境的 Python 3.10.12。
- Node.js >=22.12；兼容当前环境的 Node.js 22.23.2。
- 前端采用 React 19、TypeScript、Vite、Plotly.js、Monaco；界面文案使用中文。
- 后端采用 FastAPI、Pydantic 2、NumPy 2.2.6、SciPy 1.15.3；测试采用 pytest、Vitest、Playwright。
- 首次实现时生成并提交精确依赖锁文件；本次文档阶段不安装依赖。
- 所有计算统一使用米、秒、弧度；UI 可显示角度制，但序列化保留单位元数据。
- 数值计算与绘图刷新独立；改变回放速度或动画帧率不得改变仿真和滤波结果。
- 每次运行绑定不可变配置、模型源码、种子和版本；编辑配置只生成草稿，不修改旧结果。
- 默认服务仅监听 127.0.0.1；自定义 Python 仅用于本地用户认可的模型，工作进程提供异常和超时隔离。
- 生产代码不复用讨论草图中的示意曲线或假指标。

当前 Vite 的 Node 要求及所选数值库的 Python 兼容性可查 [Vite](https://vite.dev/guide/)、[NumPy 2.2.6](https://pypi.org/project/numpy/2.2.6/)、[SciPy 1.15.3](https://pypi.org/project/scipy/1.15.3/)。

## 3. 四装甲板几何和运动真值

### 坐标与身份

世界坐标右手系，+Z 向上。中心在 XY 平面平移。板编号 A0…A3 在目标上固定，不随当前可见板改变。两组半径定义为中心轴到装甲板中心的水平距离，板高使用绝对高度 `zA` 和差值 `dh=zB-zA`。

令参考板编号为 j，θ 是中心指向参考板中心的方向，相对世界 +X 逆时针为正：

`φ_i = θ + (i-j)π/2`

`r_i = rA（i 为偶数），rB（i 为奇数）`

`p_i = [cx+r_i cosφ_i, cy+r_i sinφ_i, zA+(i mod 2)dh]`

参考板更换属于新实验配置。观测板在同一实验内切换，不能重设 θ 的零点。外部装甲板 yaw 如果使用相反法向或其他零点，输入适配器须显式转换。A 组高度的基准不是另一个待估计的中心高度，避免冗余自由度。

该两半径、两高度的四板结构有公开实现可参考；这里使用本方案明确的方向约定，并不直接复制其 yaw 符号。[rm_auto_aim 几何实现](https://github.com/chenjunnn/rm_auto_aim/blob/main/armor_tracker/src/tracker_node.cpp)

### 自旋和中心平移

正弦项存为 `(A, frequency_rad_s, phase_rad, C)`。角度模式直接定义 θ(t)，角速度取其导数；角速度模式定义 ω(t)，积分得到连续、未包裹的 θ(t)。Ω=0 时使用常量项的极限形式，不除以零。角度图可选择连续角或包裹角，角度误差始终按模型声明的周期计算。

平移模式包括匀速、用户给定时间点的速度/方向段，以及有种子的随机平滑模式。随机模式在每 1 秒节点生成范围内的标量速度及方向，用半余弦平滑过渡；不在每个积分步重新抽速度。速度大小始终位于配置范围，方向按最短角变化。真值求解使用 `solve_ivp` 的连续输出，`max_step=simulation_dt`，`rtol=1e-8, atol=1e-10`，保证任意观测、滤波和预测目标时间都能取对应真值。

真值与观测使用独立、可重建的随机流；启用或改变纯预测不得消耗观测噪声随机数。

### 首个演示配置（全部可编辑）

时长 12 s，仿真最大步长 0.002 s，观测 100 Hz，正常滤波 50 Hz，回放 30 fps，seed=42。`rA=0.25 m,rB=0.35 m,zA=0.20 m,dh=0.08 m,reference_id=0`。速度范围 0.5…2.0 m/s；ω(t) 项为 `(1.0,1.2,0,2.0)` 和 `(0.3,3.0,0.5,0)`，初始 θ=0。提前量 `[0.1,0.3,0.5] s`。这些数字是演示配置，不是 RoboMaster 尺寸标准。

## 4. 观测流

`ObservationFrame` 含精确时间 t、板 ID 列表、观测向量、分量单位与角度索引。每块板的分量为 `[x,y,z,yaw]`，yaw 暂取该板从中心向外的方向角。多板同一帧按板 ID 排序拼接，作为一次联合校正；维数为 4×板数。

三种观测模式：

1. 指定板：始终生成配置板的理想观测，用于基础方程验证。
2. 朝向视点的单板：默认视点固定在 `(-3,0,0.2)`，从朝向视点的板中选距离最近者，距离相同时选较小 ID；没有可见板则缺测。首版可见性只按板法向与视点方向的点积 >0 判断。
3. 全部四板：生成所有板，用于分析几何状态可观测性和多板融合。

位置噪声默认各轴标准差 0.01 m，yaw 标准差 0.02 rad；支持完整真实观测协方差、缺测率和异常观测比例，默认后二者为 0。滤波器 R 与真实观测噪声分别配置。已知板 ID 是首版理想化假设；不能把真实板位置、隐藏参数或未来观测作为滤波输入。

## 5. 模型与滤波引擎

### 首个内置状态模板

`x=[cx,cy,zA,vx,vy,vz,θ,ω,rA,rB,dh]`，11 维。平移配置默认 vz=0；rA/rB/dh 为待估计的静态几何参数。首个 f 为中心匀速、恒定角速度、几何随机游走。Q 的位置/速度、角度/角速度块采用连续白加速度强度 q：

`Q_block(dt)=q[[dt³/3,dt²/2],[dt²/2,dt]]`

几何随机游走方差为 `q_geometry*dt`。默认 `q_translation=0.5,q_rotation=0.8,q_geometry=1e-6`，单位显示在编辑器中。观测函数按板 ID 调用几何投影。自旋真值可以有变角速度；滤波模型是否能跟随正是实验要评估的内容。

初始状态与 P₀ 独立填写，不由隐藏真值初始化：演示 x₀ 为 `[0,0,0.2,0,0,0,0,0,0.2,0.2,0]`；P₀ 对角标准差为 `[0.2,0.2,0.1,1,1,0.2,0.5,2,0.1,0.1,0.05]`。

### 共同契约

Model 提供状态名称/单位/角度索引，`f(x,dt,t0)`、`h(x,frame_context)`、`Q(dt)`、`R(frame)`、可选 `jacobian_f/jacobian_h`、角度感知残差和均值、物理投影及真值映射。t0 是传播起始时间，观测 context 包含观测时间；支持显式时间相关模型，不通过共享可变时钟传时间。输入函数不可访问真值轨迹或未来观测。

Filter 提供 `predict(dt)`、`update(frame)`、`snapshot()`、`restore(snapshot)`、`clone()`。更新返回校正前新息 ν、S、实际观测时间、状态与协方差。完整快照包括 IMM 子状态、模式概率、缓存和时间。

EKF 使用解析 Jacobian，缺省时可选中心差分，步长 `1e-6*max(1,|x_i|)`；观测角度差分同样处理周期。协方差使用 Joseph 更新。UKF 默认 α=0.5、β=2、κ=0，支持编辑；状态/观测均值以参考角附近局部解包，残差使用最短角差，测试必须覆盖 ±π。

协方差使用线性求解，不显式求逆。输入 P₀、R 必须正定，Q 必须半正定；错误标出矩阵与分量。数值修正仅允许可记录的相对 jitter（从 1e-12 到 1e-8），超过即判该实例失败；禁止静默用绝对值“修复”协方差。估计半径非正时报告几何投影无效，不通过静默截断掩盖。

IMM 首版子模型状态维度和语义必须一致，可混合 EKF/UKF；默认两个 CV 模型使用不同 Q 强度表示平稳/机动。混合协方差必须含模型均值差项；似然在 log 域归一化。转移配置使用连续时间生成矩阵 Λ（非对角 ≥0、每行和为 0），每步 `Π(dt)=expm(Λdt)`，`Π[i,j]=P(next=j|current=i)`；UI 同时展示参考间隔对应概率矩阵。默认两模式跳转率均为 1/s，μ₀=[0.5,0.5]。这样修改频率不会无意改变模式驻留时间。

自定义编辑器提供 Python Model 模板，可修改状态和方程；源码入口固定为 `build_model(params,geometry)->Model`，EKF/UKF/IMM 算法实现保持共享。提交在工作进程内检查元数据、维数、有限值和一次预测/观测形状，再开始数值运行。首版不承诺安全执行任意不可信代码。不同状态维度可作为独立实例比较，通过显式物理状态映射统一评估；不同维度不能直接在同一 IMM 内混合。

## 6. 时间调度和附带纯预测

### 正常循环

每实例只配置一个正常周期频率 `frequency_hz`，名义循环时刻 `t_k=k/frequency_hz`；首版不另设独立校正频率。观测流只有一份。每个循环在 `(previous_tick,t_k]` 选择最新且未消费的新观测帧，其他帧计为跳过。按实际经过时间推进到观测时间 t_obs，进行一次校正；随后从该后验生成附带纯预测，再将主状态推进剩余时间到 t_k。内部时间推进可有多个子步，但一个正常周期最多一次观测校正。

没有新观测只预测，不重复校正旧帧，也不触发“更新后”分支。t=0 的第一帧可执行 dt=0 的初始化校正。记录名义频率、实际校正数/频率、跳过帧、缺测和失败。高于观测频率的配置不是错误，但不会凭空增加观测。非整除频率也保留原始时间戳，禁止用过时观测校正已推进到未来的状态。

### 附带纯预测

仅在每次实际观测校正完成后触发附带预测，冻结起点 `(origin_time,x⁺,P⁺)`；不在单独的正常 predict 后再次触发，缺测周期也不触发。N 是提前量列表长度，每项 τ>0 表示从该起点预测 τ 秒后的状态。默认独立从同一后验副本预测；内部最大预测步长 0.005 s，最后一步精确落在目标时间。内部积分步数不是用户设置的 N。

返回 `ForecastRecord(instance_id,origin_time,lead_s,target_time,state,P,physical_projection,mode_probabilities)`。各分支不接收未来观测，主状态、模式概率、随机流和仿真时间不受影响。IMM 预测仍推进子模型和模式概率，不冻结为最后一次权重。

对齐误差：`e_τ(t)=estimate(t+τ|t)-truth(t+τ)`。保留单次更新的未来状态图，以及固定提前量随起点 t 变化的持续误差图。中心、角度、每块装甲板的位置均可选择；板匹配按固定 ID，不能因旋转把不同板当成同一板评分。可显示端点误差、RMSE、最大误差与有效样本数。超出场景时长的预测可显示，标记 truth_unavailable，不进入误差指标。未来真值只在评估阶段读取。

不同频率比较使用共同评估时刻。仅从最近的过去快照复制并预测到评估时刻，禁止插值使用未来后验。分量 RMSE 在共同均匀时间网格统计；持续误差另提供梯形积分的时间加权 RMSE。不同提前量、板 ID 和有效区间分别统计，不揉成一个总分。

## 7. 评估与建议

NIS=`νᵀ solve(S,ν)`，使用真实校正前的新息与 S；自由度等于当帧观测维数。NEES=`eᵀ solve(P,e)`，状态与真值必须同一时刻，角度采用声明残差；有真值映射的状态子集使用对应协方差子块和子集维数。没有映射的状态不计入 NEES。附带纯预测使用预测 P 计算 NEES，NIS 为 null，不能显示 0 或重复最后一次 NIS。

参考置信水平默认 95%，双侧区间用 `chi2.ppf(0.025,dof)` 和 `chi2.ppf(0.975,dof)`。每条曲线显示自由度、有效计数和适用假设。线性高斯条件下为理论参考；EKF/UKF 为近似诊断，IMM 融合分布不能宣称严格普通卡方检验通过。[混合分布检验研究](https://arxiv.org/abs/2312.17420)

支持多种子 Monte Carlo（默认按钮 20 次，数量可改），在同一时刻、相同维度的独立试验间计算 ANEES/ANIS；N 次平均统计的界为 `chi2.ppf(p,N*dof)/N`。连续时刻相关样本的均值和出界比例仅作描述统计，不套用独立样本检验。NEES/dof 可辅助阅读，不能据此跨不同状态集合直接排名。

总结按共同物理状态、提前量和有效时段比较 RMSE、偏差、最大误差、稳定性、协方差诊断、耗时及 IMM 模式概率；每条结论包含实例、参数快照和证据区间。单项“冠军”不覆盖所有状态或频率。

建议使用“异常证据 → 候选原因 → 参数试验 → 复跑验证”。首批规则覆盖初始化误差、机动段误差、系统性偏差、协方差偏保守/偏自信、观测缺失与频率收益。连续至少 50 个有效样本才生成出界比例类提示；超过 10% 的双侧出界比例是启发式提示，不是显著性判决。不能单凭 NIS/NEES 断言 Q 或 R 的唯一问题，也不能把通过检验视为参数最优。[调参研究](https://arxiv.org/abs/2306.07225)

支持复制候选配置并扫描 Q/R 强度倍率 `[0.1,0.3,1,3,10]`，复用同一观测数据；显示修改前后的多指标变化。用户显式应用候选配置才改变草稿，旧实验始终保留。

## 8. 界面和运行数据

同一个实验台中，左侧为几何/运动/观测配置，中间为四板运动视图、时间轴、状态拟合图与误差图，右侧为滤波器实例和参数。附带纯预测、NIS/NEES、总结向下扩展或折叠；不得用评估页面替换运动和拟合视图。窄屏可折行，核心图不会因切换算法参数消失。

目标视图包含 XY 轨迹、板编号/参考板、俯视结构与高度示意；首版不需要自由旋转的 3D 场景。时间游标联动观测、主估计和预测起点；区分校正点、仅预测点和附带未来状态。图表支持状态/板/实例/提前量筛选、叠加/并排以及协方差区间。

运行状态为 draft → validating → queued → running → completed/failed/cancelled。失败实例可独立停止，已成功实例继续展示；报告必须标明部分失败。配置变更显示“结果待更新”。

REST：`POST /api/runs` 创建，`GET /api/runs/{id}` 状态，`POST /api/runs/{id}/cancel` 取消，`GET /api/runs/{id}/series` 读取分页数值序列，`GET /api/runs/{id}/report` 报告，`GET /api/runs/{id}/export?format=json|csv|markdown` 导出，`POST /api/models/validate` 验证模型。初版轮询进度即可，避免在第一版增加复杂实时通信。

每个 run 在 `data/runs/<id>/` 保存 `experiment.json, models/, observations.npz, results.npz, report.json, manifest.json`；manifest 含 schema_version=1、运行版本、配置哈希、依赖版本和随机种子。不持久化可执行 pickle。前端配置持久化为 JSON。给定相同配置、源码、种子和数值依赖，数值序列可复现；运行耗时不要求一致。

构建器可自行决定配色、组件内部细分、绘图抽稀方法、UI 默认折叠状态。抽稀只影响显示，不影响评分；必须保留峰值和有效时间。性能目标先测量再给出：提供 12 s/3 实例/50 Hz/3 提前量基准，记录运行耗时、内存和图表响应，不预先许诺未经测量的实时能力。

## 9. 验收底线

四板坐标与高度差有解析对照；角度跨 ±π 无假跳变；EKF/UKF 在线性条件下与解析 Kalman 结果一致；IMM 融合包含均值差协方差，转移率随 dt 正确变化；频率非整除也不重复或错时使用观测；纯预测开关和 N 改动不影响主滤波结果；预测误差按未来目标时刻对齐；无未来真值与无新息时指标显式为空；总结和候选建议来自实际计算结果。端到端覆盖“改参数 → 跑实验 → 多开比较 → 附带预测 → 看 NIS/NEES → 试候选 → 导出并复现”。

## 10. 交付顺序

先交付可验证的几何、运动与滤波数值核心，再加入调度/纯预测和诊断，之后接到可编辑的实验台，最后完成自定义模型、候选试验、保存导出及端到端验收。完整任务、文件与验证命令见配套实施方案。
