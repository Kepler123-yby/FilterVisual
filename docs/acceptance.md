## 实际基准

`examples/baseline.json`：12 秒场景、EKF/UKF/IMM 三实例、100 Hz 观测、50 Hz 更新及评估、提前量 `[.1,.3,.5]`。运行 **1695 次实际校正，5085 次纯预测**；部分时刻无可见板，校正次数因此少于理想频率。

| 连续运行 | 计算+评估耗时 | 进程峰值内存 |
|---|---:|---:|
| 第一次 | 49.446 s | 294.8 MiB |
| 第二次 | 49.240 s | 405.2 MiB |

第二次峰值包括同一进程保留第一次结果期间的内存。两次原始数值 SHA256 均为 `1be72edbec16143bbd6873eb29f160f7e4bc1a013249dd334008ae4f19dc61f3`。预测前缀优化前耗时为 77.750/77.978 秒，数值哈希相同。基准不包括 HTTP 传输和 NPZ 压缩，不据此承诺任意配置实时运行。

普通实验默认总限时 120 秒；分析作业按计算单元数量扩大总预算：扫描包含基线，5 候选预算 720 秒；20 种子 Monte Carlo 预算 2400 秒。进度及取消仍可用，`RunStatus.timeout_s` 显示实际预算。

## 限制

首版基于已知板 ID 的合成 XYZ/yaw 观测，不含相机检测/PnP/ROS。模型必须可复制，函数应由输入及参数确定；本地可信 Python 代码在限时进程执行，不是权限沙箱。时间序列的一致性区间是描述性诊断，独立种子 MC 也需满足对应高斯近似假设；不把 IMM 近似界作为严格认证。
