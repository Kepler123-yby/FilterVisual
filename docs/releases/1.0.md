# FilterVisual 1.0

发布日期：2026-10-15。Git 标签：`1.0`；前后端包版本、API 健康检查和新运行清单版本：`1.0.0`。配置格式保持 `schema_version=1`，原配置仍可导入，已有历史运行文件不改写。

## 功能范围

- RoboMaster 四装甲板几何、固定板 ID、可设置参考板、两组半径与高度差。
- 正负 XY 平移、跨零的速度范围与节点、多项正弦角度或角速度。
- 独立真实观测噪声、丢帧和异常值；EKF、UKF、IMM 独立更新频率、初值和 Q/R。
- 自定义 Python 模型与无需 Python 的公式表单；F/H 自动计算、完整矩阵、独立 IMM 子模式。
- 每次校正后的独立未来预测分支，运动、拟合、误差、NIS/NEES、模式概率和多实例比较。
- 共同观测源 Q/R 扫描、共同有效时刻比较、独立种子 Monte Carlo、证据及参数候选。
- 本地不可变历史、配置导入、JSON/CSV/NPZ/ZIP/Markdown 导出与源码、配置、观测哈希。

安装与操作见 [README](../../README.md)、[使用说明](../getting-started.md)、[模型表单](../model-form.md) 和 [Python 模型接口](../model-authoring.md)。

## 发布前审阅与修复

1. UKF 直接计算 `alpha²(n+kappa)`，避免 `n+lambda` 消减；配置与构造阶段拒绝浮点退化尺度/权重。均值以参考点累计偏移，避免小 alpha 的大负权重让静止位置漂移。
2. 自定义模型验证补充批量状态残差与逐点实现的一致性、形状、有限性及跨角度边界检查。
3. `project(valid=False)` 的有限占位值不再进入物理误差、RMSE、排名或预测差距；界面不画无效结构和端点，轨迹在无效区间断开。状态层有效真值映射的 NEES 仍可使用。
4. 扫描统一正常仿真的评估时间网格。中心排名、界面与 CSV 使用基线和可评估候选共同有效时刻的交集；没有交集时不排名。各自时间窗口的指标保留为独立诊断。
5. 报告分开记录中心与角度的有效样本数；扫描 CSV 使用对应指标的数量，界面总网格数量明确标为“评估样本”。旧历史中缺少有效数量时不补造数值。
6. 历史实验切换后，先前取消、查询和提交的延迟响应或错误不再覆盖新选择。
7. 文档澄清角度模式的附加角偏置、各项 C 相加、噪声方差及异常倍率平方、统计假设、端口和进程管理、取消/超时与导出范围。初始设计、实施进度和旧验收保留为历史记录。

每项确认的逻辑问题均有针对性回归；发布差异经过独立复审，确认的问题已闭合。

## 适用边界

观测是已知板 ID 的合成世界坐标 XYZ/yaw，不包含相机检测、PnP、ROS 或未知 ID 关联。默认噪声为逐时独立的零均值高斯噪声，可用完整协方差表达同帧相关性；异常值使用缩放高斯混合。

自定义 Python 代码应来自可信来源；它运行在限时子进程中，该进程不是权限沙箱。模型验证是有限探针的契约检查，不证明任意时刻和输入下都正确。

EKF/UKF 的非线性高斯近似、异常值与 IMM 混合会影响 NIS/NEES 的卡方参考。时间曲线的相关样本不当作独立试验；独立种子平均指标按同一时刻及实际有效试验数统计。参数建议是带证据的候选，需要在新实验中验证。
